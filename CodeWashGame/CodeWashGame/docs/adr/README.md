# Registres de décisions d'architecture

Ce dossier regroupe les décisions qui définissent l'architecture de Level Up
RPG. Chaque décision est décrite dans un fichier numéroté qui présente son
contexte, la décision prise, les solutions envisagées et ses conséquences.

Les premières ADR décrivent l'architecture actuellement présente dans le dépôt.
Les discussions d'origine n'étant pas disponibles, les justifications exposent
les contraintes auxquelles répond l'implémentation, sans prétendre restituer
ces échanges.

## Décisions

- [ADR 0001 : Partager une application React entre le navigateur et Electron](0001-application-web-et-electron.md)

Lorsqu'une décision évolue, ajouter une nouvelle ADR décrivant la solution de
remplacement et indiquer que la décision précédente est obsolète. Ne pas
réécrire les décisions historiques.
